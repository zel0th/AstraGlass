# AstraGlass

**AstraGlass 0.2.0:** приложение собрано и проверено на macOS 27.2 (Apple silicon). [Скачать DMG и ZIP](https://github.com/zel0th/AstraGlass/releases/tag/v0.2.0) · [Изменения и проверки](docs/RELEASE-0.2.0.md). Откройте DMG и перетащите AstraGlass в «Программы». Astrolog 8.0 уже встроен в приложение; отдельная установка не нужна.

Нативное приложение для **macOS 27 и Apple silicon**: расчёты Astrolog 8.0, интерфейс SwiftUI с системными элементами Liquid Glass и локальная библиотека трактовок Авессалома Подводного.

AstraGlass использует настоящий движок Astrolog, а не самостоятельные приближённые формулы. Основные действия доступны через интерфейс Mac; расширенные режимы представлены отчётами и графикой Astrolog. Это первая версия приложения, а не полный перенос каждого окна, макроса и режима анимации оригинала.

## Возможности

- Натальная карта с выбором планет и панелью соответствующих авторских текстов.
- Таблицы положений, ретроградности, аспектов и куспидов; 40 вариантов систем домов; тропический и сидерический зодиак.
- Синастрия, транзиты на выбранную дату и транзиты на месяц через расчётные отчёты Astrolog.
- 11 графических режимов: натальная и двойная карты, композит, матрица аспектов, астрокартография, небесная сфера, горизонт, орбиты, глобус, эфемериды и календарь.
- Экспорт нативной карты в PDF/PNG, графики Astrolog в PNG/BMP, текстовых отчётов в TXT; сохранение и открытие карт в собственном JSON-формате.
- Поиск по локальным текстам без учёта регистра и е/ё, указание первоисточника каждого раздела, импорт пользовательского индекса.
- Светлое, тёмное и системное оформление, изменяемые боковые панели, стандартные меню и сочетания клавиш.

## Сборка

Требуются Mac с Apple silicon, macOS 27, Command Line Tools или Xcode с macOS 27 SDK, Swift 6.4 и Python 3.9+. Полный Xcode не обязателен. Код собирается в режиме Swift 6. Текущие скрипты создают только `arm64`, а не Universal Binary. Зависимости C++ включены в исходники; менеджер пакетов не нужен.

```sh
git clone https://github.com/zel0th/AstraGlass.git
cd AstraGlass
bash scripts/build.sh
```

После сборки скрипт печатает полный путь к `AstraGlass.app`. Откройте приложение по этому пути и скопируйте его в «Программы» для обычного использования. Каталог результата можно изменить переменной `ASTRAGLASS_BUILD_DIR`. Сборка подписана локальной ad-hoc подписью; Developer ID и нотариальное заверение Apple в проект не включены.

Для создания DMG и ZIP выполните `bash scripts/package.sh --public`: файлы в `dist/` не будут содержать авторские тексты, даже если локальный индекс существует. Личная сборка со своим индексом создаётся командой `bash scripts/package.sh --with-corpus` и получает суффикс `-personal`. Включены инструкция и отчёт о проверках; рядом сохраняются SHA-256. Скрипт монтирует готовый DMG только для чтения, проверяет подпись и расчёты встроенного движка после переноса приложения. При обычной сборке включение индекса можно отключить переменной `ASTRAGLASS_INCLUDE_CORPUS=0`.

Все необходимые исходники включены: SwiftUI-приложение, адаптер C++, исходники Astrolog и Swiss Ephemeris, атлас, локализации, шрифт с лицензией, тесты и скрипты сборки. Подмодули и скачивание закрытых бинарников не требуются. Исполняемый Astrolog находится в `AstraGlass.app/Contents/Helpers/astrolog`; его данные — в `Contents/Resources/Engine`.

## Тексты Подводного

Публичный репозиторий содержит код импортера и схему индекса. Полные книги и созданный из них индекс **не публикуются**: лицензия на код не распространяется на авторские тексты.

Чтобы использовать собственный экземпляр документов:

```sh
python3 scripts/import-interpretations.py /path/to/books.zip --output Resources/interpretations.json
bash scripts/build.sh
```

Импортер принимает ZIP, каталог DOCX или один DOCX с уровнями заголовков 1–3. Уже созданный `interpretations.json` можно подключить без пересборки через **Карта → Импортировать тексты…**. Подключённый файл сохраняется локально для последующих запусков.

На предоставленном архиве четырёх частей «Общей астрологии» проверено извлечение 823 разделов. Каждый сохраняет имя документа, исходный заголовок, SHA-256 и положение в источнике. Трактовки не генерируются: приложение показывает соответствующие авторские разделы. Для аспекта двух планет книга предоставляет отдельные тексты о проявлениях данного аспекта каждой планеты; приложение явно указывает эту структуру.

## Расчёты и ограничения

Дата вводится как местное время. Выбор города из офлайн-атласа подставляет координаты и исторический часовой пояс с учётом летнего времени на дату карты. При повторном времени требуется выбрать вхождение; несуществующее время отклоняется. Для дат до 1583 года используется явный ручной режим календаря/UTC. Ручной ввод координат и смещения сохранён.

Движок поддерживает файлы Swiss Ephemeris. Без внешних файлов основные планеты рассчитываются встроенной моделью Moshier; Хирон, астероиды и некоторые дополнительные объекты требуют соответствующих эфемерид. Недоступный объект исключается из результатов, а не показывается в нулевом градусе. Подробности сборки и адаптации находятся в [Engine/README.md](Engine/README.md).

Настройки управляют 22 объектами и 24 видами аспектов во всех видах расчёта. Круг показывает выбранные доступные объекты; отсутствующие эфемериды отмечаются явно. Графические режимы Astrolog отображаются как рассчитанные изображения; интерактивное вращение сферы и непрерывная анимация времени ещё не перенесены.

## Проверка

```sh
bash scripts/test.sh
bash scripts/test-workspace.sh
python3 scripts/benchmark.py
```

Проверки сравнивают положения планет с исходным текстовым выводом Astrolog, проверяют Julian Day, эквивалентные даты с разными смещениями UTC, системы домов, аспекты, изоляцию параллельных расчётов и формирование графики. При наличии частного индекса дополнительно проверяются источники, поиск и сопоставление текстов.

Проверки рабочего окна дополнительно подтверждают сброс устаревших результатов при изменении данных и отмену незавершённых расчётов. Отчёт и изображение не сохраняются под названием другой карты или другого режима.

В [отчёте производительности](docs/PERFORMANCE.md) описаны методика и границы измерений, включая отдельный способ измерения интерфейса. Показатель памяти тестового процесса нельзя интерпретировать как потребление всего приложения. Воспроизводимые результаты находятся в `docs/validation/`.

## English

AstraGlass is a native macOS 27 astrology application for Apple silicon, built with SwiftUI and system Liquid Glass controls. It combines the real Astrolog 8.0 engine with natal charts, synastry and transit reports, eleven graphics presets, PDF/PNG export, and a searchable local interpretation library. Users import their own Podvodny documents; the public repository does not redistribute the books. This release does not claim complete parity with every original Astrolog UI, animation, or macro feature. The source is licensed under AGPL-3.0-or-later.

Шрифт `AstraGlass Astrology` создан из Astronomicon Roberto Corona (SIL OFL 1.1) и ASCII-глифов DejaVu Sans. Исходные шрифты, лицензии и скрипт воспроизведения включены в репозиторий; обычная сборка использует готовый TTF. Источник: https://astronomicon.co/en/astronomicon-fonts/.
