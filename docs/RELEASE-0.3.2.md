# AstraGlass 0.3.2

Карта использует доступную ширину и высоту окна без прежнего ограничения 580 точками. Круг и подписи масштабируются вместе, полоса «Солнце / Луна / Асцендент» смещается вниз при увеличении высоты. В невысоком окне доступна прокрутка. Панель трактовок открывается шире и допускает ручное расширение до 1200 точек при достаточной ширине окна.

В «Мои карты» и меню «Карта» добавлены импорт и экспорт всей базы JSON. Сохраняются идентификаторы, даты и все параметры расчёта. Импорт объединяет записи по UUID: более свежая версия обновляет существующую, при одинаковой дате сохраняется локальная. Повторный импорт не создаёт дубликатов; остальные локальные карты остаются. Неверный формат, повторяющиеся UUID и повреждённые параметры отклоняются до записи. Перед изменением сохраняется резервная копия.

Txt3 исключён из приложения и выбора наборов до подготовки новой редакции пользователем. Ранее выбранный `txt3` возвращает встроенные тексты Подводного. Личный пакет содержит 823 раздела из четырёх документов; публичный пакет не содержит авторских книг. Исходный архив Txt3 сохранён локально для будущих версий. Astrolog встроен в оба пакета.

Проверки: база данных (перенос, объединение, повторный импорт, защита при ошибках), 13 групп рабочего пространства с настоящим Astrolog, шрифт/цвета/русские тексты, PDF — 18 страниц с 45 контрольными абзацами. Проверка локализации: 302 ключа без пропусков.
