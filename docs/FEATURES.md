# Возможности AstraGlass и Astrolog 8.0

AstraGlass использует расчётное ядро Astrolog 8.0. Это даёт доступ к расчётам оригинала, но не означает, что каждый режим Windows/X11 уже имеет отдельный интерфейс SwiftUI. Таблица описывает исходники 0.2.0; нативная проверка новых возможностей на macOS ещё требуется.

| Возможность | AstraGlass | Граница реализации |
| --- | --- | --- |
| Натальная карта | Нативный круг SwiftUI, выбор планеты, трактовки справа | Выбор 22 объектов; отсутствующие эфемериды явно обозначаются |
| Положения объектов | Таблица долгот, знаков, домов, директности и ретроградности | Дополнительные объекты зависят от доступности эфемерид |
| Дома | 40 пунктов выбора, таблица 12 куспидов, трактовки домов | Допустимость конкретной системы на данной широте определяется Astrolog |
| Зодиак | Тропический и сидерический | Отдельного графического редактора всех параметров аянамши нет |
| Аспекты | Нативный список с орбисами, фильтр мажорных аспектов, выбор трактовки | Все 24 вида включаются по отдельности; список учитывает выбранные объекты |
| Синастрия | Ввод/открытие второй карты, нативный двойной круг, таблица положений и точных межкартных аспектов Astrolog | Композит и остальные методы сравнения доступны через графику/отчёты движка |
| Транзиты | Нативная двойная карта и таблица на выбранную дату, отчёт на месяц | Нет непрерывной анимации времени и графического конструктора поиска событий |
| Композит и двойной круг | Графические режимы Astrolog | Отображаются как изображения с масштабированием |
| Отчёты | Положения, аспекты и матрица, мидпойнты, влияния, эфемериды, календарь, арабские части, звёзды, астрокартография | Текст сохраняет язык и формат оригинального Astrolog |
| Дополнительные параметры | Редактор аргументов расчёта и отображения | Загрузка файлов/скриптов, макросы, AstroExpression и произвольная запись из редактора отключены |
| Прогрессии и прочие расширенные методы | Расчётные функции сохранены в автономном CLI Astrolog; часть доступна параметрами отчётов | Специализированные формы и полный графический рабочий процесс не перенесены |
| Анимация, вращение и оконные команды оригинала | Статичные графические представления доступны | Полный Windows/X11 интерфейс, анимация и макросы не перенесены |
| Места и часовые пояса | Офлайн-поиск по 33 702 городам, координаты, исторический UTC/DST | Системная база IANA; неоднозначное время требует выбора; ручной режим сохранён |
| Сохранение карт | Локальная JSON-база, повторное открытие, импорт/экспорт всей базы с объединением по UUID; отдельные JSON-карты | Импорт/экспорт файлов карт `.as` из интерфейса не реализован |
| Экспорт | Карта, таблицы и трактовки в многостраничном PDF; карта PNG; графика Astrolog PNG/BMP; отчёт TXT | Нет общего редактора печатных отчётов и экспорта всех режимов в PDF |
| Тексты Подводного | Локальный импорт, поиск и привязка к карте с источниками | Полные книги отсутствуют в публичном репозитории; нет вымышленных трактовок |
| Оформление | SwiftUI/AppKit, системная навигация, Liquid Glass для элементов управления, три режима темы | Нет заявления о сертификации или формальном аудите Apple |
| Платформы | macOS 27+, Apple silicon, русский интерфейс | Intel, старые macOS и полная локализация интерфейса не входят в эту сборку |

## Одиннадцать графических режимов

Эти изображения создаёт Astrolog, а приложение показывает их в нативном окне с режимом «Вместить», изменением масштаба и сохранением PNG/BMP.

| Режим | Что используется |
| --- | --- |
| Натальная карта | Основная карта |
| Двойная карта | Основная и вторая карты |
| Композит | Основная и вторая карты |
| Матрица аспектов | Основная карта |
| Астрокартография | Основная карта |
| Небесная сфера | Основная карта |
| Местный горизонт | Дата, время и координаты основной карты |
| Орбиты планет | Основная карта |
| Земной глобус | Основная карта |
| График эфемерид | Дата основной карты |
| Календарь | Дата основной карты |

## Проверенная и непроверенная полнота

Автоматические проверки подтверждают соответствие основных положений исходному CLI, работу отчётов и создание читаемых изображений для всех одиннадцати пресетов. Они не подтверждают визуальное равенство каждого пикселя оригинальному приложению или корректность всех возможных сочетаний сотен параметров Astrolog.

Наличие 40 систем домов в списке означает доступность выбора. Проверки на южной широте охватывают семь систем; на высоких широтах применяются ограничения и поведение самого Astrolog.

Корпус содержит 13 типов аспектов. Если для элемента карты нет авторского раздела, приложение показывает отсутствие текста. Тексты об отдельном аспекте Солнца и отдельном аспекте Луны не выдаются за специальную авторскую статью об аспекте Солнце—Луна.
