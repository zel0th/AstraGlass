# AstraGlass 0.3.0

- Специализированный шрифт астрологических символов включён в приложение. Плутон использует традиционный знак с кругом, чашей и крестом; знаки зодиака, узлы, астероиды и аспекты не зависят от системной подстановки шрифта. Харон обозначается `Ch`.
- Город выбирается из раскрывающегося списка. Поиск внутри списка фильтрует результаты с первого символа; поддерживаются кириллица для распространённых городов, латиница и коды стран. Выбор подставляет координаты и исторический часовой пояс.
- В настройках выбирается набор трактовок: «Подводный · Общая астрология», «Txt3 · сборник трактовок» или импортированная библиотека. Личная сборка содержит оба предоставленных набора внутри приложения. Публичная сборка включает код импортера и не распространяет частные авторские тексты.
- Для каждой из 40 систем домов добавлено краткое пояснение; переключатель зодиака объясняет отличие тропического и сидерического вариантов. Названия вариантов на основе Антивертекса уточнены.
- «Мои карты» хранит записи в `~/Library/Application Support/AstraGlass/charts.json`. Применение данных автоматически сохраняет карту. Повторное редактирование обновляет ту же запись. Есть поиск, повторное открытие, использование в качестве второй карты и удаление с подтверждением. Сохраняются название, место, время, координаты, пояс и параметры расчёта.
- JSON записывается атомарно; предыдущая версия сохраняется как `charts.backup.json`. Повреждённая база не перезаписывается автоматически. Импорт и экспорт отдельных JSON-карт сохранены.

Проверки: 17 групп ядра, 27 проверок атласа, 11 групп рабочего пространства, 7 сценариев базы, 17 проверок импортера Txt3, покрытие шрифта и всех пояснений, PDF на 18 страниц с полными текстами и атрибуцией. Публичный и личный пакеты проверяются после переноса приложения и монтирования DMG.

Требования: Apple silicon, macOS 27+. Подпись ad-hoc; нотариальное заверение Apple не настроено.
