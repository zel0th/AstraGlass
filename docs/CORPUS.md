# Библиотека текстов Авессалома Подводного

AstraGlass показывает подлинные разделы пользовательских DOCX из серии «Общая астрология». Расчёты выполняет Astrolog; тексты выбираются из локального индекса по заголовкам и соответствующим элементам карты. Модель не генерирует трактовки и не дописывает отсутствующие главы.

## Состав проверенного архива

| Документ | Разделов в индексе |
| --- | ---: |
| Общая астрология. Часть 1. Знаки Зодиака.docx | 163 |
| Общая астрология. Часть 2. Планеты.docx | 164 |
| Общая астрология. Часть 3. Дома.docx | 325 |
| Общая астрология. Часть 4. Аспекты.docx | 171 |
| Всего | 823 |

У каждого раздела сохраняются исходный заголовок, имя файла, SHA-256 документа, иерархия заголовков и номера блоков в `word/document.xml`. Блок означает абзац или таблицу в основном теле DOCX. Это не номер страницы: пагинация Word зависит от шрифтов и параметров печати.

Абзацы сохраняются в исходном порядке; текст таблиц сохраняется по строкам, с табуляцией между ячейками. В заголовке для отображения восстанавливаются разделители, которые в Word были переносами строк. Формулировки автора не редактируются. Обложка и повторное оглавление не становятся трактовками.

## Проверенное соответствие

| Тип | Число комбинаций | Правило |
| --- | ---: | --- |
| Планета в знаке | 132 | 11 планет × 12 знаков |
| Планета в доме | 132 | 11 планет × 12 домов |
| Куспид дома в знаке | 144 | 12 домов × 12 знаков |
| Тип аспекта конкретной планеты | 143 | 13 аспектов × 11 планет |

Одиннадцать планет в текстовом корпусе: Солнце, Луна, Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Плутон и Хирон. Наличие трактовки Хирона не означает, что его позиция доступна без необходимых эфемерид. Разделы об узлах Луны учитывают направление пары северного и южного узлов.

Корпус содержит аспекты 0°, 30°, 36°, 45°, 60°, 72°, 90°, 108°, 120°, 135°, 144°, 150° и 180°. Для аспекта двух планет приложение возвращает авторские разделы о данном типе аспекта каждой планеты и общий раздел о типе аспекта. Отдельные тексты о каждой из двух планет нельзя представлять как написанную автором трактовку их конкретной пары. Для углов, отсутствующих в книгах, метод возвращает пустой список.

Часть 1 и часть 2 содержат разделы о планетах в знаках. Они сохранены с отдельными источниками, даже когда заголовки совпадают. Поиск выполняется по заголовку и полному тексту без учёта регистра и различия е/ё; совпадения заголовков показываются раньше совпадений в тексте.

## Импорт собственного экземпляра книг

Нужен Python 3.9 или новее; сторонние библиотеки не требуются.

```sh
python3 scripts/import-interpretations.py /path/to/books.zip --output Resources/interpretations.json
```

Вместо ZIP можно передать каталог DOCX или один DOCX. Импортер рассчитан на документы с корректными стилями заголовков уровней 1–3. Для сохранения локальных исходных DOCX добавьте `--preserve-docx PrivateCorpus`.

`scripts/build.sh` включает найденный `Resources/interpretations.json` в локальную сборку. В приложении можно импортировать уже созданный JSON; он сохраняется в `~/Library/Application Support/AstraGlass/interpretations.json` и имеет приоритет над встроенным индексом. До замены проверяются формат, версия схемы и уникальность идентификаторов.

## Публичный исходный код и частные тексты

Права на тексты принадлежат их правообладателям. Передача архива пользователем для локальной обработки не устанавливает разрешение на публичное распространение книг. Поэтому `PrivateCorpus/` и `Resources/interpretations.json` исключены из Git; публичный проект содержит импортер, схему и код чтения. Публичная сборка без индекса предлагает импортировать свой экземпляр. Личная сборка может включать локально предоставленный индекс.

Структура индекса описана в `Resources/Interpretations.schema.json`. Семантические ключи `planet-sign:1:0`, `planet-house:1:1`, `house-sign:1:0` и `aspect-planet:90:1` используют идентификаторы объектов Astrolog, нумерацию домов с 1 и знаков с 0 (Овен).
