# AstraGlass 0.1.0

Первая версия для macOS 27+ и Apple silicon. Расчётное ядро — Astrolog 8.0; интерфейс — SwiftUI/AppKit. Основные возможности и ещё не перенесённые режимы перечислены в [FEATURES.md](FEATURES.md).

Личная сборка содержит 823 раздела из предоставленных четырёх документов Авессалома Подводного. Публичные исходники и публичный режим упаковки не содержат книг или индекса текстов.

Перед выпуском исправлена ситуация, в которой после изменения исходных данных старое изображение или отчёт оставались доступны для экспорта. Теперь изменение данных отменяет зависимые задания и очищает их результаты; названия и содержимое для сохранения фиксируются вместе. Изменение второй карты не сбрасывает независимый натальный расчёт.

Проверки: 14 групп расчётов, текстов и всех 11 графических режимов; 6 групп состояния рабочего окна. Подробные результаты и ранее выполненные измерения CPU/памяти находятся в [PERFORMANCE.md](PERFORMANCE.md) и `validation/`.

Установка: распакуйте ZIP и перенесите `AstraGlass.app` в «Программы». Сборка подписана ad-hoc, без Developer ID и нотариального заверения. Она не устанавливает дополнительные службы.

Ограничения: нет полного переноса всех окон, макросов и анимаций оригинала; смещение UTC и координаты задаются вручную; объекты, требующие отсутствующих внешних эфемерид, исключаются из результатов. Эти ограничения не скрываются нулевыми положениями или сгенерированными трактовками.
