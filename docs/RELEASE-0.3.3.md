# AstraGlass 0.3.3

- Соединения можно выбирать прямо на круге: у каждой пары есть синий значок ☌. Точные совпадения и стеллиумы не превращаются в невидимые или наложенные друг на друга области нажатия. Доступны подписи для VoiceOver и переход к трактовке.
- Трины зелёные, квадраты красные, соединения синие. Единая палитра используется кругом и списком аспектов; нативный экспорт карты использует тот же круг.
- Дома слегка подсвечены по естественным стихиям: 1/5/9 — огонь, 2/6/10 — земля, 3/7/11 — воздух, 4/8/12 — вода. Сектора следуют фактическим куспидам, включая переход через 0°.
- Месяц, день и час выбираются из выпадающих списков. Год и минуты вводятся вручную. Дни ограничены выбранным месяцем; смена месяца/года корректирует 31-е число и 29 февраля при необходимости. Сохранена проверка исторического UTC и неоднозначного летнего времени.
- Кнопка «Из библиотеки…» в основном и втором редакторе загружает сохранённую карту с поиском по названию, месту и дате. До «Применить» изменения существуют только в редакторе. Применение обновляет выбранную запись, сохраняя её идентификатор; другая ранее открытая карта не перезаписывается. Отмена ничего не сохраняет.

Проверено: 18 групп расчётного модуля с настоящим Astrolog, 27 проверок атласа, 14 групп рабочего пространства, календарные переходы, раздельные цели для 10 точных соединений, 12 секторов домов, шрифт и палитра. PDF сохраняет все 45 контрольных абзацев на 18 страницах. В интерфейсе проверены выбор соединения, февраль 2000/2001, список часов, ручные минуты, поиск и загрузка карты с автоматическим UTC и отмена без изменения исходной карты.

Astrolog и рабочие данные встроены в приложение. Личный пакет содержит 823 раздела Подводного из четырёх документов. Публичные исходники и установочные файлы не содержат авторских книг или личных карт. Txt3 остаётся исключённым. Подпись локальная ad-hoc; Developer ID и нотариальное заверение отсутствуют.
