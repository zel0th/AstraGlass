# Расчётный модуль AstraGlass

В AstraGlass используется настоящий Astrolog 8.00, опубликованный 31 мая 2026 года. Исходники в `Upstream/Astrolog` получены из `https://github.com/CruiserOne/Astrolog`, commit `5bf172ea231c4b6ea3d7e09ca307571354a41e8a`. Содержимое исходников сохранено; окончания строк нормализованы в LF.

`bash scripts/build-engine.sh` собирает нативный исполняемый файл `Engine/bin/astrolog`. Xcode не обязателен: достаточно Command Line Tools с C++ и Swift. Исполняемый файл содержит все расчётные и текстовые режимы Astrolog, а также генерацию файлов графики (SVG, PostScript и другие форматы). X11 и Windows UI не компилируются.

В копии исходников для сборки применены две адаптации: отключён `X11`; объекты с ошибкой получения эфемерид исключаются из расчёта вместо отображения ошибочной позиции 0°. Оригинальные файлы в `Upstream` не изменяются. `Bridge.cpp` добавляет режим `--json`, который сериализует настоящие массивы положений, домов и аспектов Astrolog. В нём также сокращается `argv[0]`, чтобы длинный путь macOS app bundle не переполнял старый 255-байтовый путь поиска эфемерид. Рабочая директория процесса должна быть каталогом ресурсов приложения.

## Интерфейс процесса

```sh
cd Upstream/Astrolog
../../Engine/bin/astrolog --json -qb 1 1 2000 12:00 0 0 0 51.5 '=b' _k _k0 -YQ 0
```

После `-qb`: месяц, день, год, местное время, летняя поправка, пояс к западу от UTC, долгота к западу, широта к северу. Swift API преобразует привычные пользователю восточную долготу и смещение `local − UTC` в эти соглашения. `julianDay` в JSON — астрономический Julian Date UT с дробной частью, а не целочисленный номер местной даты.

`unavailableObjects` содержит номера объектов, исключённых из-за недоступных эфемерид. При отсутствии файлов Swiss использует встроенную модель Moshier для основных планет; астероиды и некоторые дополнительные объекты требуют файлов. Нельзя считать координаты отсутствующего объекта нулевыми. Файлы `_18.se1` покрывают 1800–2399 годы. За пределами этого диапазона нельзя обещать ту же полноту объектов без дополнительных эфемерид.

Swift API запускает каждый расчёт отдельным процессом вне главного потока, передаёт аргументы без shell, отключает сеть, запись файлов и AstroExpression, ограничивает длительность и вывод, завершает процесс при отмене. Редактор текстовых отчётов дополнительно исключает загрузку скриптов и макросов. Автономный CLI сохраняет оригинальные режимы Astrolog для опытного пользователя.
